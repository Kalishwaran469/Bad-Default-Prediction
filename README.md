# Bad Debt Prediction – Streamlit Application (AWS EC2 Deployment)

## Project Overview
This project is a machine learning–based web application that predicts whether a customer is likely to become a bad debt customer.  
The application is built using **Streamlit** for the user interface and a **CatBoost classification model** for prediction.  
The trained model is deployed on an **AWS EC2 instance**.

---

## Objective
- Predict customer default risk using historical data
- Provide a simple and interactive UI for prediction
- Deploy the application on AWS EC2 using Streamlit

---

## Technologies Used
- Python
- Streamlit
- Pandas, NumPy
- Scikit-learn
- CatBoost
- AWS EC2 (Ubuntu)
