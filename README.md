# Dynamic Bad Debt Prediction Model for Credit Risk Assessment (AWS EC2 Deployment)

## Overview

An end-to-end Machine Learning project developed to dynamically predict whether a customer is likely to become a bad debt customer before loan approval. The solution helps banks, NBFCs, and lending institutions assess credit risk, reduce potential loan defaults, and make data-driven lending decisions.

The project covers the complete machine learning lifecycle, including data preprocessing, feature engineering, model training, evaluation, web application development, and cloud deployment on AWS EC2. The deployed application enables real-time customer risk prediction through an interactive web interface accessible over the internet.

## Key Features

* Predicts customer default risk before loan approval
* Machine learning-based credit risk assessment system
* Interactive web application for real-time predictions
* Automated data preprocessing and prediction pipeline
* Dynamic risk evaluation based on customer information
* Cloud deployment using AWS EC2
* Publicly accessible through a web browser
* Supports faster and more informed lending decisions
